about=Imports AIXM 5.x XML (BasicMessage and other feature collections) into a GeoPackage and adds styled layers to the project. Every feature with geometry is shown with its attributes; airspaces are composed from their geometry components (union / subtraction of contributor airspaces, arcs, circles and border-following via GeoBorder xlinks). Several files can be imported together - or added later to the same GeoPackage, e.g. a missing GeoBorder file - so xlinks resolve across files. Feature classes can be selected per import. Timeslices are reduced to the state valid at a chosen date. Gaps and misaligned airspace boundaries are reported as issues on the map.
