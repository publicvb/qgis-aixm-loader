PROJECT DESCRIPTION:

The aim is to develop full scale plugin for QGIS which will fully support AIXM 5.1/5.1.1/5.2 models. If an AIXM feature/object has a geometry, it will be possible to have it depicted in QGIS together with the attributes. Including complex airspaces and similar features, where the geometry is composed of other geometries of other features / inhereted from other features, using their uuids for xlinks.
